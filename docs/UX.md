# UX Foundation

Goosegrass uses native macOS interaction patterns. The planned primary navigation is Today, Inbox, Appointments, Calendar, Customers, Follow-up, History, and Settings.

The default experience should answer five questions quickly: who is coming today, who is next, who has not been contacted, who did not arrive, and who needs follow-up.

Phase 0 contains only an accessible informational shell. Feature navigation, tables, inspectors, quick add, search, materials, and visual tokens are implemented in their roadmap phases. Visual polish must never outrank data correctness, traceability, reminders, or recoverability.
